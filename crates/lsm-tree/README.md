# brk_lsm_tree

BRK-maintained fork of [`lsm-tree`](https://github.com/fjall-rs/lsm-tree), published separately for use by the [Bitcoin Research Kit](https://bitcoinresearchkit.org). Its Rust library name remains `lsm_tree`.

`lsm-tree` is a minimal implementation of log-structured merge trees written in Rust.
